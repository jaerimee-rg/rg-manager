# FAQ 챗봇 (학부모 질문 채팅) — 요구사항 문서

리듬체조 출석 관리 시스템에 **FAQ 관리 메뉴**와 **학부모용 AI 질문 채팅창**을 추가하기 위한 요구사항 문서 모음입니다.

## 한 줄 요약

관리자(학원 계정 사용자)가 FAQ를 등록하면, 사용자마다 발급되는 고유 링크로 학부모가 로그인 없이 접속해 질문할 수 있고, AI가 **등록된 FAQ 내용만 근거로** 답변합니다. 관련 FAQ가 없으면 답변하지 않고 안내 문구를 보여주며, 모든 대화는 관리자 화면에서 확인할 수 있습니다.

## 핵심 설계 결정 요약

| 항목 | 결정 | 근거 |
|---|---|---|
| FAQ 소유 단위 | 사용자(`userId`)별 | 기존 students/classes/competitions 와 동일한 멀티테넌시 패턴 |
| 채팅 링크 | 사용자당 채널 1개 자동 생성, `/chat/:publicId` | "각 사용자마다 각자의 채팅창" 요구사항 |
| 링크 공유 | FAQ 화면 상단 우측 **공유 아이콘**으로 복사 (링크 배너 없음) | 화면을 단순하게 유지 |
| 학부모 진입 | **대화명 입력 후** 채팅 시작 | 관리자 화면에서 문의자 구분 |
| FAQ 분류 | 카테고리 없음 (질문·답변만) | 운영 단순화 |
| 링크 인증 | 추측 불가능한 랜덤 토큰(`publicId`), 로그인 불필요 | 학부모는 계정이 없음 |
| AI 근거 | 해당 사용자의 공개 FAQ 전체를 프롬프트에 주입 (벡터 DB 없음) | FAQ 수십~수백 건 규모, 인프라 추가 없이 정확도 확보 |
| 답변 없을 때 | AI가 `answered: false` 반환 → 서버가 고정 안내 문구로 대체 | 환각(hallucination) 차단 |
| AI 제공자 | **Google Gemini** (`@google/genai`, 기본 모델 `gemini-2.5-flash`) | API 키는 루트 `.env`의 `GEMINI_API_KEY` |
| 대화 열람 | 관리자 화면 `/faq/chats`, 관리자 전용 `/admin/faq` | 요구사항 6번 |
| 관리자 답변 | 대화 상세에서 직접 답변 전송 (학부모 화면에 "선생님" 말풍선) | 2026-08-22 추가 |
| AI 자동 답변 | 채널 설정에서 on/off. 끄면 접수 안내만 남기고 관리자가 직접 답변 | 2026-08-22 추가 |

## 확정이 필요한 사항 (문서에는 권장안으로 기술)

1. **메뉴 위치** — 권장: 메인 네비게이션에 `FAQ` 추가(사용자별 관리) + `/admin/faq`(전체 사용자 조회). 요구사항의 "관리자 화면"을 `/admin` 전용으로 한정하면 사용자별 채팅창을 만들 수 없으므로 두 곳 모두 두는 안을 기본으로 잡았습니다.
2. **학부모 이름 입력** — 권장: 선택 입력(미입력 시 "학부모"로 표기). 필수로 바꿀지 확인 필요.
3. **AI 비용 상한** — 채널별 일일 질문 수 상한 기본값 200건으로 제안. 운영 정책에 따라 조정.
4. **모델** — `gemini-2.5-flash` 기본. 비용을 더 낮추려면 `gemini-2.5-flash-lite`, 품질이 필요하면 `gemini-2.5-pro` (환경변수 `FAQ_CHAT_MODEL`).
4. **미답변 질문 → FAQ 전환 버튼** 등 편의 기능은 MVP 범위 밖(2차)으로 분리했습니다.
