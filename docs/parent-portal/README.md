> **상태: 1차 MVP 구현 완료** (2026-08-23). 구현 내용은 `CLAUDE.md` 의 Parent Portal 절과
> `03-implementation-plan.md` 의 단계별 계획을 참고하세요. §10 확장 요구사항은 아직 미구현입니다.

리듬체조 출석 관리 시스템에 **학부모 계정**과 **학부모 포털(일정 · 이벤트 신청)**, 그리고 이를 뒷받침하는
선생님용 **이벤트 관리**를 추가하기 위한 요구사항 문서 모음입니다.

원본 메모: [../학부모.md](../학부모.md) (이 문서는 그 메모의 0~2번과 선생님 0~3번을 MVP 로 구체화한 것입니다.)

## 한 줄 요약

선생님이 **초대 링크**를 학부모에게 보내면, 학부모는 링크 → **카카오 가입** → **아이 이름·생년월일 입력**만으로
계정을 만들고, 로그인하면 **일정** 메뉴에서 선생님이 등록한 **대회 · 스페셜 이벤트 · 휴관일**을 **올해 남은 순서대로 카드 리스트**로 보고,
대회·이벤트는 **옵션을 골라 신청하고 자유롭게 취소**할 수 있습니다. 선생님은 기존 **대회 관리** 메뉴가 확장된
**이벤트 관리**에서 세 종류의 이벤트를 등록하고 신청 현황을 봅니다.

## 현재 시스템에서 출발하는 지점

| 이미 있는 것 | 이번에 하는 일 |
|---|---|
| `users.role` = `admin`(시스템 관리자) / `user`(선생님). 카카오 로그인은 **항상 선생님 계정**을 만든다 | `parent` 역할 추가. 초대 링크를 거친 카카오 로그인만 학부모 계정을 만든다 |
| `students` (이름·생년월일, `userId` 로 선생님에게 귀속) | 학부모가 입력한 아이 이름·생년월일로 **선생님의 학생에 자동 연결** |
| `competitions` + `competition_students` (종목·참가비·출강비), `학생별 대회` 화면 | 새 `events` 테이블이 일정의 단일 출처. 대회형 이벤트는 기존 `competitions` 행과 1:1 로 연결해 **기존 화면을 그대로 살린다** |
| 헤더 메뉴 `대회 관리` (`/competitions`) | `이벤트 관리` (`/events`) 로 확장 — 대회 / 스페셜 이벤트 / 휴관일 등록 + 신청 현황. 학부모 관리는 새 **`학부모`** 메뉴(`/parents`) |
| FAQ 채팅의 `publicId` 링크, 상단 공유 아이콘, 카카오 알림 유틸 | 같은 패턴으로 초대 링크 · 링크 복사 · (선택) 신청 알림 |

## 핵심 설계 결정 요약

| 항목 | 결정 | 근거 |
|---|---|---|
| 학부모 식별 | `users.role = 'parent'`, **카카오 로그인 전용**(비밀번호 없음) | 기존 인증·JWT 그대로 사용, 화면 분기는 role 하나로 |
| 학부모 ↔ 선생님 | 학부모는 **초대한 선생님 1명**에게 속한다 (`parent_accounts.teacherId`) | 일정·학생 매칭 범위를 한 선생님으로 한정 |
| 초대 링크 | 선생님당 **재사용 가능한 링크 1개**, 재발급 가능, 만료 없음(선택적 만료) | FAQ 채널 링크와 같은 운영 감각. 단체 카톡방에 한 번 올리면 끝 |
| 가입 중 아이 입력 | 이름+생년월일이 선생님의 학생과 **정확히 일치하면 자동 연결**, 아니면 **"확인 대기"** 로 가입은 완료 | 오타로 가입이 막히지 않게. 선생님이 학부모 메뉴에서 수동 연결 |
| 이벤트 저장 | 새 `events` 테이블 (type = `competition` / `special` / `closure`). 대회형은 `competitions` 행과 1:1 | 휴관일이 `학생별 대회`·참가비 화면에 섞이지 않게, 기존 대회 기능 무회귀 |
| 이벤트 옵션 | 이벤트마다 선생님이 자유 입력하는 라벨 목록(id 고정), 학부모는 **다중 선택** | "옵션 (다중 선택)" 요구. 가격·정원은 2차 |
| 신청 / 취소 | 신청은 **자녀 단위**, 취소는 신청 가능 기간 안에서 **자유**. 취소는 소프트(이력 유지) | "취소도 자유롭게". 선생님은 취소 이력까지 본다 |
| 대회 신청 → 확정 | 학부모 신청은 `event_registrations`, 선생님이 **확정** 하면 기존 `competition_students` 에 추가 | 원본 메모의 "신청 → 확정 → 참가비" 흐름. 종목·참가비는 기존 화면 그대로 |
| 접근 제어 | 학부모 JWT 는 `/api/parent/*` 만, 선생님 API 는 학부모를 **전부 거부** | 지금은 `verifyToken` 만 있어 역할 검사가 없다 — 반드시 추가 |
| 시스템 관리자 | `/admin/parents` 에서 전체 학부모 목록(선생님 필터)·연결·삭제 | 2026-08-23 요청 |
| 메뉴 | 선생님: `대회 관리` → `이벤트 관리`, 새 **`학부모`** 메뉴(초대 링크 + 학부모↔학생 연결, 학부모별/학생별 보기). 학부모: `일정` 하나(향후 확장) | 학부모 관리를 이벤트와 분리(2026-08-23 결정). 학부모 포털 메뉴는 레이아웃만 확장 가능하게 |
| 일정 화면 | **달력 없이** 오늘~올해 12/31 이벤트를 날짜순 **카드 리스트**로. 월 구분 헤더·D-day | "캘린더 보이지 말고 올해 남은 일정만 카드로" 요구. 조회도 한 번이면 끝 |

## 확정이 필요한 사항 — MVP (문서에는 권장안으로 기술)

2026-08-23 답변으로 **학부모 대회 흐름 = 선생님이 만든 옵션 체크 → 신청/취소** 가 확정됐다(#4 의 2단계 구조는 그대로). 아래는 아직 답이 없는 MVP 항목이며, 답이 없으면 권장안으로 진행한다.

| # | 질문 | 권장안 |
|---|---|---|
| 1 | "현재 **대화** 관리 메뉴를 이벤트 관리로 확장" — 대화 관리 메뉴는 없어 **대회 관리**로 해석했다. 맞는지? | 대회 관리 → 이벤트 관리 |
| 2 | 초대 링크는 선생님당 1개 재사용? 매번 새 링크(만료)? | 1개 재사용 + 재발급. 만료는 선택 |
| 3 | 아이 정보가 선생님 학생과 안 맞을 때 가입을 막을지, 받아두고 선생님이 연결할지 | 받아두고 "확인 대기" → 선생님이 수동 연결 |
| 4 | 대회 신청을 **신청(학부모) → 확정(선생님)** 2단계로 둘지, 신청 즉시 참가 학생으로 넣을지 | 2단계 (메모의 흐름과 일치) |
| 5 | ~~학부모 목록·수동 연결 화면 위치~~ | **결정: 별도 `학부모` 메뉴**, 학부모별/학생별 양방향 연결 |
| 6 | ~~초대 링크 복사 버튼 위치~~ | **결정: 학부모 메뉴** 상단 우측 아이콘 + 링크 박스 |
| 7 | 신청·취소 마감 기준 | 기본: 이벤트 시작 전까지. 선생님이 마감 일시를 따로 정하거나 접수를 닫을 수 있음 |
| 8 | 휴관일은 기간(여러 날) 지원? | 지원 (시작일~종료일) |
| 9 | 한 학부모에 자녀 여러 명? 한 자녀에 학부모 여러 명(엄마·아빠)? | 둘 다 지원 |
| 10 | 학부모 신청/취소 시 선생님 카카오 알림 | MVP 에 **선택**으로 포함 (기존 알림 유틸 재사용, 관리자 > 알림에서 on/off) |
| 11 | "올해 남은 일정만" 이면 12월에 내년 1~2월 이벤트가 안 보인다. 그대로 둘지, 내년 이벤트가 있으면 아래에 "내년 일정" 으로 이어 보여줄지 | 내년 일정 섹션 (선택 FR-49) |
