학부모
0. 학부모 가입 (아이 이름, 아이 생년 월일로 가입), 카카오로 가입 (재림 링크)
1. 일정 확인 (대회, 특강, 휴관일, 러닝) -> 달력
2. 대회 신청 -> 기존 참가 학생 따로 관리 
 -신청 (신청 -> 확정 -> 참가비, 출강비, 의상비)
3. 사진 공유
 -대회 사진 Google Drive 업로드, 볼 수 있게
 -대회 사진 애들 사진 등록, 자기의 애들 사진만 볼 수 있게 필터
4. 게시판
5. 채팅
